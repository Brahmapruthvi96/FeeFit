# FeeFit: Personalised Banking

DSV project website by Brahma Pruthvi (ENG24CT0003, CST Dept).

A single-page static site: no build step, no dependencies. Open `index.html` in a browser.
The live demo uses simulated numbers, labelled on the page.

## Files
- `index.html` the whole website (HTML, CSS and JavaScript)
- `FeeFit_Presentation.pptx` the presentation offered on the Downloads section

## Publish with GitHub Pages
Repository Settings > Pages > Deploy from a branch > `main` / root.
